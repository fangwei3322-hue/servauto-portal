NEW-TAB SINGLE-FILE VERSION

This version fixes the “file deleted / file not found” problem.

How it works:
- Open index.html.
- Click “7 ClearWash”.
- ClearWash opens in a NEW browser tab.
- The ClearWash page is embedded inside index.html itself.
- There is NO clearwash.html link and NO second file dependency.

So even if you only upload/use index.html, button 7 can still open ClearWash.

If a browser blocks the new tab, allow pop-ups for the site and click button 7 again.
